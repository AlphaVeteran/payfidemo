PayFi Demo — System Architecture

Next.js frontend (frontend/) talks to a separate Express process (src/server.ts) via REST. wagmi/viem connect the browser to JSON-RPC; server-side viem performs reads and signed txs. PostgreSQL (or memory) stores intents and settlement outbox rows. Primary public demo chain: HashKey Chain Testnet (133); Base Sepolia and local Anvil remain supported. HashKey Gateway (reusable order → payment_url, redirect_url → /payment/result?intentId=…), merchant GET /payments reconciliation, and webhooks are optional integration paths.
