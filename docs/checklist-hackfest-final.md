# Global Hackfest 2026 Final Checklist

Use this checklist before submission deadline to avoid missing required items.

## A. Product and Code Readiness

- [ ] End-to-end flow runs successfully: create intent -> fund escrow -> release/refund.
- [ ] Conflux usage is real and visible in code and demo (not only mentioned in docs).
- [ ] Smart contract address and explorer links are confirmed.
- [ ] Main repository is public.
- [ ] License is open-source (MIT / Apache-2.0 / GPL-3.0).

## B. Repository Documentation

- [ ] Root `README.md` includes project overview, setup, and run instructions.
- [ ] `docs/hackfest-2026-submission.md` is filled with real links and final wording.
- [ ] Go-to-market plan is present and complete.
- [ ] Team information is complete and correct.
- [ ] Third-party tools/libraries/AI assistance are credited if used.

## C. Required Media

- [ ] Demo video (3-5 minutes) is uploaded and publicly accessible.
- [ ] Participant intro video (30-60 seconds) is recorded and publicly accessible.
- [ ] Video links are added to submission docs.

## D. Hackathon Submission Actions

- [ ] Add project entry under `/projects/` in your fork of the hackathon repo.
- [ ] Open PR from your fork to `conflux-fans/global-hackfest-2026`.
- [ ] Fill the required GitHub submission issue template.
- [ ] Open PR to `electric-capital/open-dev-data` for your project.
- [ ] Publish tweet/social post tagging `@ConfluxDevs` and `@ConfluxNetwork`.

## E. Final QA Pass

- [ ] Fresh run on a clean shell follows README without hidden steps.
- [ ] Key environment variables are documented and sanitized (no secrets committed).
- [ ] Screenshots/recordings match current UI and current chain config.
- [ ] All links in docs are clickable and non-placeholder.
- [ ] Submission is completed before deadline (UTC).
